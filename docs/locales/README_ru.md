# DevLens

<p align="center">
  <img src="../assets/lensy.svg" alt="Lensy" width="260" />
</p>

DevLens — браузер для разработчиков, ориентированный на рабочий процесс.

Он показывает один URL одновременно в мобильном и десктопном кадре, предоставляет консоль и сеть в реальном времени, HTTP-перехватчик и повторитель, живое редактирование дизайна, отчеты разведки, AI-ассистента и быстрый переход в редактор.

## Ключевые возможности

- Иммерсивные темы workspace в панели вкладок, навигации и боковой панели.
- Двойной просмотр viewport с синхронизацией прокрутки.
- Tab Groups с названиями, цветами, перетаскиванием, контекстным меню и свертыванием.
- Split View показывает две существующие вкладки без их перезагрузки.
- Защита WImH с защитой содержимого и предупреждениями об угрозах.
- Интеграция DevTools: Elements, Console, Network и Application.
- Умный omnibox с историей, закладками, трафиком и подсказками.
- Изоляция workspace и профиля через отдельные partitions Electron.

## Технологический стек

- Electron 44
- Vite 7
- React 19
- TypeScript (strict)
- Tailwind CSS 4

## Быстрый старт

Выполните эти команды из каталога `outputs/devlens`:

| Скрипт | Описание |
| --- | --- |
| `npm install` | Установить зависимости |
| `npm run dev` | Запустить Vite и Electron с HMR |
| `npm run build` | Проверить типы и собрать out/ |
| `npm run start` | Запустить собранное приложение |
| `npm run typecheck` | Выполнить tsc --noEmit |

## Сочетания клавиш

| Действие | Сочетание |
| --- | --- |
| Новая вкладка | `Ctrl+T` |
| Закрыть вкладку | `Ctrl+W` |
| Обновить страницу | `Ctrl+R` |
| Найти на странице | `Ctrl+F` |
| Открыть настройки | `Ctrl+,` |
| Новая приватная вкладка | `Ctrl+Shift+P` |
| DevTools оболочки | `F12` |
| Панель Elements | `Ctrl+Shift+I` |
| Панель Console | `Ctrl+Shift+J` |
| Панель Network | `Ctrl+Shift+E` |
| Боковая панель | `Ctrl+Shift+B` |
| Режим Ghost | `Ctrl+Shift+G` |
| Защита WImH | `Ctrl+Shift+H` |
| Последняя вкладка | `Ctrl+Tab` |
