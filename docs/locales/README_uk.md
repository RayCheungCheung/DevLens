# DevLens

<p align="center">
  <img src="../assets/lensy.svg" alt="Lensy" width="260" />
</p>

DevLens — браузер для розробників, орієнтований на робочий процес.

Він показує одну URL-адресу одночасно в мобільній і стільничній рамці, надає консоль і мережу в реальному часі, HTTP-перехоплювач і повторювач, живе редагування дизайну, звіти розвідки, AI-асистента та швидкий перехід до редактора.

## Основні можливості

- Імерсивні теми workspace в панелі вкладок, навігації та бічній панелі.
- Подвійний перегляд viewport із синхронізацією прокрутки.
- Tab Groups з назвами, кольорами, перетягуванням, контекстним меню та згортанням.
- Split View показує дві наявні вкладки без їх перезавантаження.
- Захист WImH із захистом вмісту та попередженнями про загрози.
- Інтеграція DevTools: Elements, Console, Network і Application.
- Розумний omnibox з історією, закладками, трафіком та підказками.
- Ізоляція workspace та профілю через окремі partitions Electron.

## Технологічний стек

- Electron 44
- Vite 7
- React 19
- TypeScript (strict)
- Tailwind CSS 4

## Швидкий старт

Виконайте ці команди з каталогу `outputs/devlens`:

| Скрипт | Опис |
| --- | --- |
| `npm install` | Встановити залежності |
| `npm run dev` | Запустити Vite та Electron з HMR |
| `npm run build` | Перевірити типи та зібрати out/ |
| `npm run start` | Запустити зібраний застосунок |
| `npm run typecheck` | Виконати tsc --noEmit |
