# DevLens

<p align="center">
  <img src="../assets/lensy.svg" alt="Lensy" width="260" />
</p>

DevLens هو متصفح مطورين مبني حول سير العمل.

يعرض الرابط نفسه في وقت واحد داخل إطار للجوال وإطار لسطح المكتب، ويوفر وحدة تحكم وشبكة مباشرة، ومعترض HTTP ومكرر، وتحريرًا مباشرًا للتصميم، وتقارير استطلاع، ومساعدًا ذكيًا، وانتقالًا فوريًا إلى المحرر.

## الميزات الأساسية

- سمات مساحة عمل غامرة لشريط التبويبات وشريط التنقل والشريط الجانبي.
- معاينة بمساحتي عرض مع مزامنة التمرير.
- مجموعات تبويبات بالأسماء والألوان ودعم السحب والقائمة السياقية والطي.
- Split View لعرض تبويبين موجودين بدون إعادة تحميلهما.
- حماية WImH مع حماية المحتوى وطبقة تنبيهات التهديدات.
- أدوات مطورين مدمجة: Elements وConsole وNetwork وApplication.
- شريط عناوين ذكي مع السجل والإشارات المرجعية والاقتراحات.
- عزل مساحة العمل والملف الشخصي عبر أقسام Electron منفصلة.

## البنية التقنية

- Electron 44
- Vite 7
- React 19
- TypeScript بوضع strict
- Tailwind CSS 4

## البداية السريعة

شغّل هذه الأوامر من مجلد `outputs/devlens`:

| الأمر | الوصف |
| --- | --- |
| `npm install` | تثبيت الاعتماديات |
| `npm run dev` | تشغيل Vite وElectron مع HMR |
| `npm run build` | فحص الأنواع ثم بناء out/ |
| `npm run start` | تشغيل التطبيق المبني |
| `npm run typecheck` | تشغيل tsc --noEmit |
